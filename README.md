# Konexio
Projet Konexio : page Internet de commandes de plats dans un restaurant
🌊 Bienvenue dans le projet Te Moana Nui, une application web interactive d'un restaurant de spécialités tahitiennes (Ma'a Tahiti). 
Ce projet permet d'afficher la carte du restaurant et de simuler la prise de commande avec un calcul dynamique du prix total du panier.
📌 Présentation du projet :
Ce projet est une application front-end simple développée en HTML5, CSS3 et JavaScript. L'objectif principal est d'offrir une interface conviviale pour découvrir les plats traditionnels polynésiens et de proposer un système interactif de commande.
Features (fonctionnalités) :
Carte interactive : présentation dynamique des entrées, plats, desserts et boissons.
Ajout au panier au clic : il suffit de cliquer sur le nom d'un produit pour l'ajouter à la commande.
Calcul dynamique du panier : le total en euros se met à jour automatiquement en temps réel.
Navigation rapide : des boutons ancres en bas de page permettent de naviguer directement vers la section souhaitée.
Suivi console : un récapitulatif textuel complet s'affiche dans la console développeur à chaque ajout de produit.
🛠️ Technologies utilisées :
HTML5 : structuration sémantique de la page.
CSS3 : mise en forme globale, palettes de couleurs thématiques et alignements (Flexbox).
JavaScript (ES6) : manipulation du DOM, gestionnaires d'événements (click, DOMContentLoaded) et algorithmes d'accumulation (reduce, find).
